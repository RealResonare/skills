# Thread Library — 螺纹参数库

> **中文说明**：这是 3D 打印中"加螺纹/装螺丝"的权威参数参考：标准公制螺纹、间隙孔、热熔嵌件、沉头/螺母坑，以及直接打印螺纹的建模规范。所有数值单位毫米；标准依据 ISO 261 / ISO 724 / ISO 273 / DIN 912 / ISO 4032。

## 1. Decision Flow — 四种加螺纹方式怎么选

| 方式 | 适用场景 | 强度/复用 | 成本 | 结论 |
|---|---|---|---|---|
| **间隙孔 + 螺母/螺母坑** | 外壳、支架、一般装配（默认首选） | 可反复拆装不磨损 | 低 | 默认方案 |
| **热熔嵌件** (heat-set insert) | 常开合的电子壳、治具、产品原型 | 金属螺纹，可反复拆装 | 中（嵌件成本） | 需要可靠金属螺纹时 |
| **攻丝** (手攻) | PLA/PETG 的 M3+、低应力、一次固定 | 会磨损/滑丝，高扭矩易失效 | 低 | 一次性/低应力 |
| **直接打印螺纹** | 瓶盖、装饰盖、非承重连接 | 粗牙 M6+ 且细层高才可靠 | 低 | M6 以下 FDM 不可靠 |

> 中文提醒：无论哪种方式，先打 10 分钟试块验证孔径再打整件——每台打印机/耗材的实际孔径都有偏差。

## 6. Printed Threads — 直接打印螺纹的建模规范

**适用性：** 仅 **M6 及以上粗牙**，配合 **0.12–0.20mm 层高**，FDM 才能清晰成型；M6 以下牙型太小会糊成一团。适合瓶盖、装饰盖、非承重连接 [$TRAE_REF](https://grandpacad.com/en/tools/thread-tap-calculator)。

设计规则：
- **牙型**：梯形/锯齿形优于 V 形（60°）——V 形牙尖在 FDM 上易碎、难配合。
- **牙距**：≥ 0.8mm（M8 以上）；最小 0.4mm 但极难打印。
- **公差**：外螺纹 `d − 0.3mm`，内螺纹 `D + 0.3mm`（打印螺纹间留 0.3mm 配合间隙）。
- **首尾收牙**：两端各留 0.5–1 牙的平段（不完全螺纹），避免崩牙。
- **垂直打印**：螺纹轴线沿 Z 轴打印质量最好；水平螺纹顶面会有台阶/悬垂，慎用。
- **补偿**：外螺纹径向 −0.2mm，内螺纹径向 +0.2mm（FDM 挤出膨胀）。

### OpenSCAD 建模示例（梯形牙，linear_extrude + twist）

```scad
$fa = 1; $fs = 0.2;
pitch    = 1.5;            // 牙距 (mm)，粗牙
major_d  = 8.0 - 0.3;      // 外螺纹：名义径 − 配合间隙
thread_h = 12;
tooth_w  = pitch * 0.55;   // 梯形牙宽

module male_thread() {
    linear_extrude(height = thread_h, twist = -360 * thread_h / pitch, convexity = 10)
        polygon([
            [0, -major_d/2],                       // 根部
            [tooth_w, -major_d/2 + tooth_w*0.6],   // 牙顶(内圈)
            [tooth_w,  major_d/2 - tooth_w*0.6],   // 牙顶(外圈)
            [0,  major_d/2]                        // 根部
        ]);
}
male_thread();
```

> 中文：更精确的 ISO 牙型可用现成库（如 BOSL2 `threaded_rod()`/`threaded_hole()`，或 `threads.scad`）。优先引用库，别手写公式。

## 7. Orientation Rules — 孔方向规则

- **竖直孔**（沿 Z 轴）比水平孔圆且准；水平孔顶面有层纹台阶会略呈椭圆。
- 孔直径越小、越要竖直放。
- 需要配合的孔，先做 10mm 试块（含目标孔径 ±0.1mm 梯度）验证。
