# 示例:RC 低通滤波器完整设计闭环

本文件展示 electricDesign 的完整交付格式,Agent 可对照本样例执行任何电路设计任务。

## 任务
设计一个一阶 RC 低通滤波器:输入方波 0~3.3V、频率 1kHz,要求衰减 50kHz 以上噪声 ≥ 20dB,负载阻抗 ≥ 100kΩ,直流无衰减。

## 1. 需求澄清
| 参数 | 值 |
| --- | --- |
| 输入信号 | 0~3.3V 方波,基频 1kHz |
| 目标 | fc 使 50kHz 处衰减 ≥ −20dB |
| 负载 | ≥ 100kΩ |
| 精度 | 无特殊要求,常规 5% |

## 2. 模板匹配
匹配模板 `templates/RC低通高通滤波.md`(一阶低通)。

## 3. 参数计算
- 一阶低通高频衰减约 −20dB/十倍频,要 50kHz 处 −20dB,需 fc ≈ 5kHz。
- fc = 1/(2πRC):取 C = 10nF(C0G),R = 1/(2π × 5k × 10n) ≈ 3183Ω → 取 E24 值 **3.3kΩ**。
- 实际 fc = 1/(2π × 3.3k × 10n) ≈ 4.82kHz;50kHz 处衰减 = 20·log10(1/√(1+(50/4.82)²)) ≈ −20.4dB ✅
- 负载效应:滤波器输出阻抗 ≈ 3.3kΩ ≪ 100kΩ(负载影响 <3.4%)✅

| 参数 | 公式 | 计算值 | 实际取值 |
| --- | --- | --- | --- |
| R | 1/(2π·fc·C) | 3183Ω | 3.3kΩ(E24) |
| C | 目标 fc 反推 | 10nF | 10nF(E12) |
| fc | 1/(2πRC) | 4.82kHz | ≈4.8kHz |

## 4. 自检结果
1. 功率:无直流电流,功耗 ≈ 0 ✅
2. 耐压:C0G 10nF ≥ 25V 耐压,最大电压 3.3V ✅
3. 电流:无电流应力 ✅
4. 精度:5% 电容导致 fc 误差约 ±5%,在可接受范围 ✅
5. 频率:一阶滚降满足 −20dB@50kHz 需求(−20.4dB)✅
6. 负载效应:3.3kΩ vs 100kΩ ✅
7. 极性:无极性元件 ✅
8. 数字侧:输出仍为 0~3.3V 电平(直流无衰减)✅

## 5. SPICE 网表
```spice
* RC 低通:fc≈4.8kHz,输入 1kHz 方波 0~3.3V
V1 in 0 PULSE(0 3.3 0 1u 1u 499u 1m)
R1 in out 3.3k
C1 out 0 10n
.tran 1u 3m
.end
```

## 给用户的补充说明
- 若噪声频率更接近信号,需提高阶数(两级 RC)或用运放有源滤波。
- 方波通过低通后边沿变缓,若后续是数字输入,注意上升沿时间 2.2τ ≈ 2.2×33µs ≈ 73µs。
