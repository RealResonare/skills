# 运放放大电路

## 适用场景
同相放大(高输入阻抗)、反相放大(精确增益)、电压跟随器(缓冲)、差分放大(减法/传感器)。运放型号拿不准时给出选型依据(GBW、失调、轨到轨、供电),不要虚构具体型号参数。

## 电路结构
```
同相:                     反相:                    跟随器:
Vin ──┤+  ──┬── Vout      Vin ── Rg ──┤−  ── Vout    Vin ──┤+  ──┬── Vout
      │     │ Rf                    │     │ Rf              │     │
      ├−  ──┘                      ├+  0 V               ├−  ──┘
      │                            │                     (输出直接接 −)
      └────────┘                   └────────┘
(反馈网络:Rg 下端接地,Rf 跨接 − 与输出)
```

## 关键公式
- 同相:Vout = Vin × (1 + Rf/Rg);输入阻抗 ≈ 运放共模阻抗(极高)
- 反相:Vout = −Vin × (Rf/Rg);输入阻抗 ≈ Rg
- 跟随器:Vout = Vin,输入阻抗极高,输出阻抗极低
- 差分(4 电阻):Vout = (Rf/Rg)·(V2 − V1)(取 R1=R3=Rg、R2=R4=Rf)
- 增益带宽积:GBW = 增益 × 带宽,信号带宽须 ≪ GBW/增益(经验留 10× 裕量)

## 参数计算步骤
1. 确定拓扑:信号源内阻大/需隔离 → 跟随器或同相;需要负增益/输入阻抗无要求 → 反相;共模干扰 → 差分或仪表放大器。
2. 确定增益 G,选 Rg(常用 1k~10k),Rf = G·Rg(反相)或 Rf = (G−1)·Rg(同相)。
3. 校验带宽:Rf/Rg 与运放 GBW 决定可用带宽;Rf 过大会与输入寄生电容形成极点,精密高频场合 Rf∥Cf 补偿。
4. 校验直流误差:失调电压 VOS、输入偏置电流 IB(乘源阻抗)、共模抑制、电源纹波抑制对输出的总误差 ≤ 目标精度。

## 自检要点
- **带宽**:GBW/(1+Rf/Rg) ≥ 10 × 目标信号带宽。
- **输出摆幅**:Vout 峰值须在运放输出摆幅内(轨到轨或留 1~2V 裕量),且输出电流 ≤ 运放最大输出电流。
- **输入共模范围**:同相与跟随器输入电压须落在共模输入范围(VICR)内。
- **失调误差**:VOS + IB·Rs 折算到输出后 ≤ 目标精度;精密应用选低失调运放或加调零。
- **稳定性**:大 Rf + 负载电容易自激,输出串小电阻或加反馈电容。

## 示例网表(同相放大 11 倍)
```spice
* 同相:Vout = Vin×(1+10k/1k)=11×;Vin=0.5V → 5.5V
* 用行为源 E1 模拟理想运放(增益 100k,负反馈):
V1 in 0 DC 0.5
Rg fb 0 1k
Rf out fb 10k
E1 out 0 VALUE {100000*(V(in)-V(fb))}
.op
.end
```
仿真可看到 V(out) ≈ 5.5V。真实器件请用厂商 SPICE 模型(如 uA741、TL072 等 .lib 文件)替换 E1,并把行为源理想特性与真实运放的差异(失调、摆幅、GBW)在交付中说明。LTspice 中可直接用 `opamp2` 符号 + 同相配置。

## 常见坑
- 同相放大忘算共模范围 → 输出正确但接近 VICR 边缘畸变。
- Rf 取到 1MΩ+ → 输入偏置电流与寄生电容导致增益误差、带宽骤降。
- 反相放大输入阻抗就是 Rg → 源阻抗高时增益被拉偏,先缓冲再放大。
