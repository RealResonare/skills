# 三极管开关

## 适用场景
电平转换、继电器/负载开关、LED 驱动、数字→功率接口。NPN 低侧开关最常用;高侧开关用 PNP 或 PMOS。

## 电路结构
```
低侧 NPN 开关:
VCC ──(负载)──┬── 集电极 C
              │
              NPN(发射极 → GND)
              │
Vin ── RB ── 基极 B
```

## 关键公式
- 基极电阻:RB = (VIN − VBE)/IB,取 VBE ≈ 0.7V
- 深饱和条件:IB ≥ IC/β_min × (3~10)(取 β 的 1/10~1/20,保证 VCE_sat ≈ 0.2V)
- IC = (VCC − VCE_sat)/R_LOAD ≈ VCC/R_LOAD
- 功耗:P_Q = VCE_sat × IC(开关状态,很小);P_RB = (VIN−VBE)²/RB

## 参数计算步骤
1. 确定负载电流 IC(继电器、LED、负载电阻决定)。
2. 查三极管最小 β(如 2N2222 在 IC=150mA 时 β_min≈100),取安全系数 10:IB = IC/10。
3. RB = (VIN − 0.7)/IB,取 E24 值(取小一点保证饱和)。
4. 校验:VIN 高电平必须 > VBE + IB·RB;VIN 低电平须确保 VBE < 0.5V 关断。

## 自检要点
- **饱和确认**:VCE_sat 仿真/实测 < 0.3V 才算饱和;不饱和时管子发热严重。
- **基极电流限制**:VIN 是 5V/3.3V 逻辑时 IB 别超规格书最大基极电流。
- **感性负载**:继电器/电机必须并在负载两端反向续流二极管(1N4007/SS14),否则关断瞬间击穿三极管。
- **关断漏电**:高阻负载或高温时 Iceo 可能误开通,必要时加基极下拉电阻(10k~100k)。
- **开关速度**:高速开关(>10kHz)需加速电容或专用驱动器,普通 RC 开关有存储时间。

## 示例网表(5V 逻辑驱动 12V 继电器)
```spice
* IB = (5-0.7)/4.3k ≈ 1mA,IC = 12/120 ≈ 100mA → β_实际 ≈ 100
Vcc vcc 0 DC 12
Vl vin 0 DC 5
RB vin b 4.3k
RL vcc c 120
Q1 c b 0 2N2222
.model 2N2222 NPN(IS=1e-14 BF=200 VAF=100)
D1 c vcc 1N4007
.model 1N4007 D(IS=1e-12 N=1.5)
.tran 1u 2m
.end
```
观察 V(c) 由 12V 跳到 ≈0.2V 即饱和。

## 常见坑
- 继电器不并续流二极管 → 关断时反电动势击穿管子(最常见故障)。
- 用 β 典型值而不是最小值算 IB → 批次差的管子不饱和。
- 拿 NPN 做高侧开关 → 发射极电位被抬升,无法完全导通;高侧用 PNP/PMOS。
