# LED 限流

## 适用场景
指示灯、LED 驱动(恒压源直接驱动)。要求恒流(亮度不随电源变化)时改用恒流源或 LED 驱动 IC。

## 电路结构
```
VCC ── R ──┬── LED 阳极
           │
          LED(阴极 → GND)
```

## 关键公式
- 限流电阻:R = (VCC − VF)/IF
- LED 压降 VF(典型,查规格书):红 ~1.8V、绿 ~2.0V、蓝/白 ~3.0V;IF 典型 5~20mA(指示灯 2~10mA 即可)
- 电阻功耗:P = I²·R = (VCC − VF)·IF

## 参数计算步骤
1. 查 LED 规格:VF 与目标 IF(或按上述典型值)。
2. R = (VCC − VF)/IF,向上取 E24 标准值(取大一点更安全,亮度略降)。
3. 算 P,选 1/4W 或 1/8W(留 ≥2× 裕量)。

## 自检要点
- **功耗**:P ≤ 额定 50%。
- **VCC 波动**:电源上限时电流 I = (VCC_max − VF_min)/R 是否超 LED 额定(建议 ≤ 额定 80%)。
- **并联 LED**:同型号并联必须各自串电阻,否则电流分配不均(不要共用一个电阻)。
- **反向耐压**:LED 反向耐压通常只有 5V 左右,交流驱动需并联反向二极管。

## 示例网表
```spice
* 5V 驱动红色 LED,IF=10mA:VF≈1.8V → R≈320Ω,取 330Ω
V1 vcc 0 DC 5
R1 vcc a 330
D1 a 0 LED
.model LED D(IS=1e-14 N=1.8)
.op
.end
```
仿真中查看 I(D1) ≈ 9.7mA。

## 常见坑
- 用 5V 直接接 LED 无电阻 → 烧毁。
- 多个 LED 共用一个限流电阻 → 亮度不均、先烧最弱的一颗。
- 电池供电电压下降后 LED 明显变暗 → 改用恒流方案。
