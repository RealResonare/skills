# MOSFET 开关

## 适用场景
低侧/高侧功率开关、负载开关、电机/加热器驱动、逻辑电平切换大电流。比三极管适合大电流与高速。

## 电路结构
```
低侧 NMOS(推荐):              高侧 PMOS:
VCC ──(负载)──┬── D             Vin ──(负载)──┬── S
              │                              │
            NMOS S → GND                    PMOS D → 负载
              │                              │
Gate ── RG ── G                Gate ── RG ── G(低电平导通)
```

## 关键公式
- 导通条件:VGS 须超过阈值 VGS(th) 足够裕量,并尽量接近 10V/额定值以获得低 RDS(on)
- 导通损耗:P = I² × RDS(on)(RDS(on) 在 VGS=10V 与目标电流下查规格书)
- 开关损耗(高频时):P_sw ≈ ½·VDS·ID·(t_rise+t_fall)·f
- 栅极电阻 RG:限制栅极充放电电流,抑制振铃(常用 10~100Ω)

## 参数计算步骤
1. 选拓扑:低侧用 NMOS(便宜、RDS(on) 小);高侧大电流用 PMOS(注意 RDS(on) 通常较大)。
2. 确定 VGS 驱动能力:逻辑电平 3.3V/5V 驱动必须选"逻辑电平 MOSFET"(VGS(th) ≤ 1~2V),否则用栅极驱动 IC 升压。
3. 校验电压/电流:VDS_max ≥ 2× 实际最高电压;ID 额定 ≥ 2× 实际电流。
4. 算损耗与散热:RDS(on) 损耗 vs 开关损耗,决定是否需散热片。

## 自检要点
- **VGS 裕量**:VGS 应 ≥ 3~4× VGS(th) 才有低 RDS(on);3.3V 逻辑直驱普通 MOSFET(如 IRF540,VGS(th) 2~4V)会半导通发热。
- **体二极管**:MOSFET 内含体二极管,关断感性负载时它可续流但压降大、速度慢;大电流感性负载建议仍加肖特基。
- **栅极振铃**:长栅极走线 + 高 di/dt 会振铃,加 RG(10~100Ω)或栅极-源极电阻(10k~100k)。
- **米勒平台**:高速开关注意驱动电流能否快速灌入 Ciss,必要时用驱动 IC。
- **反向**:NMOS 源漏接反会导通体二极管,方向务必核对。

## 示例网表(逻辑电平 NMOS 低侧开关,5V 负载)
```spice
* VGS=3.3V 驱动,负载 2Ω → ID≈2.5A
Vdd vdd 0 DC 5
Vg gate 0 DC 3.3
RL vdd d 2
M1 d gate 0 0 IRFZ44N
.model IRFZ44N NMOS(Level=1 VTO=2 KP=20)
.tran 100n 100u
.end
```
观察 V(d):导通时 ≈ VDS = ID×RDS(on),应远小于 5V。注意:普通 VTO 模型无法精确模拟 RDS(on),仿真仅供定性验证,交付时说明。

## 常见坑
- 3.3V MCU 直驱普通 NMOS → 半导通、发热,必须用逻辑电平型号或驱动 IC。
- 高侧 NMOS 需要比电源更高的栅极电压(自举/电荷泵),直接用会烧或不通。
- 忽略开关损耗:高频 PWM 时开关损耗 > 导通损耗。
