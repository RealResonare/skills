# 电阻分压器

## 适用场景
电压衰减、ADC 分压采样、直流偏置、参考电压。注意:分压器带载能力差,负载较重时请改用稳压器或缓冲器。

## 电路结构
```
Vin ── R1 ──┬── Vout
            │
           R2
            │
           GND
```

## 关键公式
- Vout = Vin × R2/(R1+R2)
- 输出阻抗(从 Vout 看):Zout = R1∥R2 = (R1·R2)/(R1+R2)
- 分压比 k = R2/(R1+R2)
- 静态电流 I = Vin/(R1+R2)

## 参数计算步骤
1. 由目标分压比确定 k = Vout/Vin。
2. 确定静态电流 I:经验取负载电流的 ≥10 倍,保证负载效应 ≤10%;电池供电时在功耗与稳定性间取舍(常用 10µA~1mA)。
3. R1+R2 = Vin/I;R2 = k·(R1+R2);R1 = (R1+R2) − R2。
4. 取 E24 系列标准值,用标准值反算实际分压比,确认误差 ≤ 目标精度。

## 自检要点
- **负载效应**:Zout 应远小于负载电阻(建议 Zout ≤ 负载的 1/10),否则输出电压会跌穿。
- **功耗**:PR1、PR2 各自 ≤ 额定功率 50%。
- **ADC 场景**:Zout 与 ADC 采样电容组成 RC,充放电时间常数须远小于采样周期;高阻分压还会引入热噪声与偏置电流误差。
- **精度**:1% 电阻的分压比误差约 ±2%(两个电阻容差叠加);精密场合用 0.1% 或可调电阻。

## 示例网表
```spice
* 分压器:Vin=5V, k=0.5, 静态电流 1mA
V1 in 0 DC 5
R1 in out 4.7k
R2 out 0 4.7k
.op
.end
```

## 常见坑
- 用分压器当"电源"带负载 → 电压立刻跌穿,先算输出阻抗。
- 只算分压比不管电流预算 → 电池场景静态功耗失控。
- 阻值选到 1MΩ 以上 → 热噪声、PCB 漏电流、ADC 偏置电流误差放大。
