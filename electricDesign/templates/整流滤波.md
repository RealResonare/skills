# 整流滤波

## 适用场景
交流转直流(AC→DC):半波(低成本小电流)、全波(中心抽头变压器)、桥式整流(最常用)。输出带纹波,要求平滑后续接 LDO 或 DC-DC。

## 电路结构
```
桥式整流 + 电容滤波:
AC1 ──┤┌┐├──┬── Vout
      │└┘│   │
      │  │  C1
      │  │   │
AC2 ──┤└┘├──┴── GND
(四个二极管组成桥;C1 为滤波电容)
```

## 关键公式
- 空载峰值:Vpeak = √2 × Vrms
- 带载直流:Vdc ≈ √2 × Vrms − 2 × VD(桥式,VD≈0.7~1V;肖特基 0.3~0.5V)
- 纹波电压(近似):Vripple ≈ I_load / (2 × f × C)(全波,f=市电频率 50Hz 的 2 倍即 100Hz;半波用 50Hz)
- 滤波电容:C = I_load / (2 × f × Vripple_target)
- 电容耐压:≥ 1.5 × Vpeak(电解电容必须留裕量)

## 参数计算步骤
1. 确定输出直流目标与纹波要求(如 12Vdc、纹波 < 0.5V)。
2. 算 C = I_load/(2·f·Vripple),取 E12 系列(常见 470µF~4700µF)。
3. 校验耐压:Vpeak = √2×Vrms,电容耐压 ≥ 1.5×Vpeak。
4. 二极管:反向耐压 ≥ 2×Vpeak;平均电流 ≥ 2×I_load;峰值电流(电容充电浪涌)要能承受,必要时加 NTC 限流。
5. 若后级有 LDO,纹波要求可放宽(LDO 会再抑制);若直供负载,按负载容忍度定纹波。

## 自检要点
- **浪涌电流**:上电瞬间电容充电电流极大,电源内阻小的地方要串 NTC 或限流电阻。
- **电容寿命**:纹波电流超过电容额定会发热;电解电容在高温下寿命骤减。
- **安全隔离**:市电整流必须用隔离变压器,严禁直接整流市电给低压电路(触电风险),并在交付中明确提示。
- **空载电压**:空载时输出接近 √2×Vrms,高于带载值,后级耐压要按空载算。
- **二极管选型**:普通 1N4007(1A/1000V)够大多数小功率场景;大电流用桥堆或肖特基。

## 示例网表(12V 交流桥式整流,100mA 负载)
```spice
* 12Vrms → Vpeak≈17V,整流后带载 ≈15V,纹波用 C=1000uF 压到 ≈0.5V
Vac 1 0 SIN(0 16.97 50)   ; 12Vrms 的峰值
D1 1 2 1N4007
D2 0 2 1N4007
D3 2 1 1N4007
D4 2 0 1N4007
C1 2 0 1000u IC=0
Rload 2 0 150            ; 100mA
.model 1N4007 D(IS=1e-12 N=1.5)
.tran 10u 100m
.end
```
观察 V(2):稳态约 14~15V,纹波 ≈ 0.5V。

## 常见坑
- 电容耐压按 √2×Vrms 算 → 空载时电容爆裂(必须 1.5× 以上)。
- 小电容大负载 → 纹波巨大,后级 LDO 都压不住。
- 整流桥四个二极管方向接错一个 → 短路烧保险。
- 直接整流市电无隔离 → 人身安全风险,必须提醒。
