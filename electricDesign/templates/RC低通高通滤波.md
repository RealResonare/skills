# RC 低通/高通滤波

## 适用场景
一阶滤波:低通(去高频噪声、抗混叠、积分平滑)、高通(去直流、隔直耦合、微分)。多级可级联成高阶,但每级相互加载,注意阻抗隔离。

## 电路结构
```
低通:                         高通:
Vin ── R ──┬── Vout           Vin ── C ──┬── Vout
           │                            │
           C                             R
           │                            │
          GND                          GND
```

## 关键公式
- 截止频率(±3dB 点):fc = 1/(2πRC)
- 一阶幅频:增益 G = 1/√(1+(f/fc)²)(低通);G = (f/fc)/√(1+(f/fc)²)(高通)
- 相移:低通滞后 φ = −arctan(f/fc);高通超前 φ = 90° − arctan(f/fc)
- 时间常数 τ = RC;阶跃响应 1τ=63.2%、3τ=95%、5τ=99.3%
- 高频衰减(低通,f ≫ fc):约 −20dB/十倍频

## 参数计算步骤
1. 由 fc 与负载确定 C(常用 100nF~1µF 起步),再算 R = 1/(2π·fc·C)。
2. 复核输出阻抗:低通的 R 即源阻抗,负载应 ≥ 10R;高通输出阻抗约等于 R。
3. 取 E 系列标准值,反算实际 fc,确认落在目标带宽内。

## 自检要点
- **负载效应**:后级输入阻抗必须 ≫ 滤波器输出阻抗,否则 fc 漂移。
- **电容选择**:精密滤波用 C0G/NP0;X7R 次之;大容量 X5R 注意 DC 偏压降容。
- **源阻抗**:前级源阻抗会与 R 串联改变 fc,高频精密场合要计入。
- **数字信号**:滤噪声时 fc 应远离信号基频与谐波,避免波形畸变。

## 常见坑
- 后级负载太轻(R_L 接近 R)→ fc 明显偏移。
- 电解电容当滤波电容,漏电与 ESR 破坏精度。
- 高通"隔直"后忘记给后级提供直流偏置 → 输出悬浮。
