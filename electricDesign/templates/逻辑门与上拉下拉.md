# 逻辑门与上拉下拉

## 适用场景
数字电平接口:MCU GPIO 输入上拉/下拉、开漏输出上拉、总线( I²C、SPI、UART)电平、逻辑门接口匹配、按键消抖。

## 电路结构
```
输入上拉(默认高):             开漏输出上拉:
VCC ── R_pull ──┬── GPIO      VCC ── R_pull ──┬── 总线/对方输入
                │                            │
             按键/开集 ── GND               开漏输出(低导通)
```

## 关键公式与规则
- 逻辑电平判据:高电平输入 V_IH ≥ 0.7×VCC(常见 TTL/CMOS 5V 时 2.0V;3.3V CMOS 约 0.7×3.3≈2.31V);低电平 V_IL ≤ 0.3×VCC
- 输出:CMOS 高电平 V_OH ≈ VCC(微安级负载),低电平 V_OL ≈ 0V;TTL 有差异,查规格书
- 上拉电阻范围:
  - 下限(驱动能力):R ≥ (VCC − V_OL)/I_OL(开漏灌电流限制)
  - 上限(噪声/速度):R ≤ (V_IH − 0)/I_leak(漏电流),且 R·C_线 ≤ 上升时间要求/2.2(边沿 RC)
  - 常用值:普通 GPIO 上拉 4.7k~100k;I²C 用 2.2k~10k(与总线电容、速度匹配);开漏 LED 由限流算
- 下拉电阻:对称规则,低功耗时取大(10k~100k)

## 参数计算步骤
1. 明确接口类型:推挽输出(不需上拉)、开漏/开集(必须上拉)、三态(悬空时需上拉或下拉定电平)。
2. 按驱动能力定下限、按漏电流/边沿定上限,取中间常用值。
3. I²C 等总线:按总线电容与标准速率算上升时间 t_r = 0.8473 × R × C_bus ≤ 规格上限(100kHz:≤1µs;400kHz:≤300ns)。
4. 按键输入:上拉 + 软件消抖;必要时加 RC 硬件消抖(时间常数 ~1~10ms)。

## 自检要点
- **逻辑电平匹配**:3.3V 输出接 5V TTL 输入通常可行(TTL V_IH≈2V);5V 输出接 3.3V 输入必须分压/电平转换,禁止直连。
- **上拉电流**:I²C 上拉太小 → 灌电流超规格;太大 → 边沿太慢、噪声。
- **悬空输入**:未接的 CMOS 输入悬空会振荡、耗电,必须上拉/下拉或接固定电平。
- **总线冲突**:两个推挽输出直连同一根线会打架;总线用开漏 + 上拉。
- **去耦**:每个逻辑 IC 的电源脚加 0.1µF 去耦电容,高速时加 10µF 储能。

## 示例网表(开漏 + 上拉,RC 仿真边沿)
```spice
* 开漏输出:NMOS 低侧,上拉 4.7k,总线电容 50pF
Vcc vcc 0 DC 3.3
Rp vcc bus 4.7k
Cb bus 0 50p
M1 bus gate 0 0 NMOS
.model NMOS NMOS(VTO=1 KP=2m)
Vg gate 0 PULSE(0 3.3 0 10n 10n 20u 40u)
.tran 10n 80u
.end
```
观察 V(bus) 上升沿:τ=RC=4.7k×50p≈235ns,10%~90% 上升时间 ≈ 2.2τ ≈ 520ns。

## 常见坑
- 开漏输出忘加上拉 → 总线永远低电平或悬空乱跳。
- 5V 逻辑直连 3.3V MCU → 烧 IO,必须电平转换(分压/74LVC/双向电平转换)。
- 上拉选 1k 大电流接口长期发热,I²C 灌电流超限。
- CMOS 输入悬空 → 静态电流大、逻辑乱,可能振荡。
