# DFM Checklist — 可制造性检查清单

> **中文说明**：交付 Gerber 前逐项核对本清单。数值为通用参考，最终以你选的板厂制程能力表为准。红色（**加粗**）项是导致生产失败率最高的关键项。

## 1. 线宽与间距 (Trace & Spacing)

| 检查项 | 标准 | 说明 |
|---|---|---|
| **最小线宽满足制程** | 4mil(1oz)/5mil(2oz)/8mil(3oz) | 太细蚀刻不稳定易断线 |
| **最小间距满足制程** | 外层 4mil / 内层 3.5mil | 蚀刻钻蚀导致短路 |
| 线宽满足载流 | IPC-2152；1oz/10mil ≈ 0.5A 外层 | 细线过流发热烧断 |
| 差分对间距一致 | 偏差 <10% | 阻抗不连续反射 |
| 走线到板边距离 | 0.25mm(V-cut)/0.15mm(铣边) | 板边切割损伤走线 |
| **无锐角走线(<45°)** | 45° 或圆弧 | 酸阱过蚀开路 |
| 瓶颈段检查 | 颈部宽度满足载流 | BGA 扇出瓶颈电流瓶颈 |
| 泪滴 (teardrop) | 过孔焊盘必需，SMD 建议 | 增强焊盘与走线连接强度 |

## 2. 过孔 (Via)

| 检查项 | 标准 | 说明 |
|---|---|---|
| **钻孔尺寸满足孔径比** | ≤8:1 标准 / 10:1 先进 / 12:1 HDI | 深孔电镀不良断孔 |
| 过孔间间距 | ≥0.2mm（标准）/0.15mm（HDI） | 钻头偏摆破环 |
| 过孔到走线间距 | ≥0.15mm（环形圈边缘） | 短路 |
| **环形圈 (annular ring)** | ≥0.1mm（标准）/0.075mm（HDI） | 钻孔偏移断连接 |
| Via-in-pad | 树脂填充+电镀盖帽（IPC-4761 Type VII） | 不填焊料会沿孔爬走 |
| 盲埋孔叠层可制造 | 钻程表按层对提供 | 叠层不可制造返工 |
| **平面连接热焊盘** | 4 辐条，辐条宽 0.25mm | 直连吸热焊不牢 |
| 高速背钻 | >5Gbps 指定背钻深度+0.2mm 余量 | 残桩谐振劣化信号 |

## 3. 阻焊与丝印 (Solder Mask & Silkscreen)

| 检查项 | 标准 | 说明 |
|---|---|---|
| **阻焊开窗正确** | 比焊盘外扩 ≥1mil | 开窗小桥连，大露铜 |
| 阻焊桥（细间距脚间） | 尽量保留（<0.5mm 脚距） | 桥连风险 |
| 丝印文字高度 | ≥0.8mm | 清晰可读 |
| 丝印不压焊盘/过孔 | 避开或改层 | 影响焊接/检测 |
| 极性/位号标记 | 二极管、电解、IC 1 脚 | 装配防呆 |
| 板名/版本号 | 丝印标注 | 追溯 |

## 4. 拼板与板框 (Panelization & Outline)

| 检查项 | 标准 | 说明 |
|---|---|---|
| 板框尺寸与结构图一致 | 螺钉孔/限高/接地 ±0.2mm 公差 | 装配对不上 |
| V-cut 与铣边选择 | 异形板用铣边+V 槽 | 分板方式 |
| 拼板工艺边 | ≥5mm 工艺边+定位孔 | SMT 轨道 |
| 邮票孔桥连接 | 桥宽/间距按板厂 | 分板毛刺 |
| 板内异形槽 | 标注锣槽 | 铣刀半径限制 |

## 5. 铜平衡与平面 (Copper Balance & Planes)

| 检查项 | 标准 | 说明 |
|---|---|---|
| 铜面平衡 | 各层铜率接近（±20%） | 翘曲 |
| 大铜皮网格 vs 实心 | 大电流实心，普通网格 | 焊接/散热 |
| 平面分割 | 避免高速信号跨分割 | 回流路径断裂 |
| 孤立铜皮 (island) | 清除或接地 | 天线效应/DFM 警告 |
| 散热铺铜 | 功率器件下方过孔阵散热 | 温升 |

## 6. 装配 (DFA)

| 检查项 | 标准 | 说明 |
|---|---|---|
| 元件间距 | SMD ≥0.3mm；THT ≥1.5mm | 贴片/插件干涉 |
| 极性元件方向统一 | 位号统一朝向 | AOI/人工检查 |
| 元件到板边 | ≥1mm（无工艺边时） | 分板损伤 |
| 高元件与低元件相邻 | 避免回流阴影 | 大器件遮挡小器件 |
| 测试点 | 关键网络留测试点（≥1mm 焊盘） | 飞针/ICT |

## 7. 叠层与阻抗 (Stackup & Impedance)

| 检查项 | 标准 | 说明 |
|---|---|---|
| **完整叠层表** | 材料/厚度/Dk 每层提供 | 阻抗计算前提 |
| **阻抗目标定义** | 50Ω SE / 90-100Ω diff，容差 ±10% | 高速网必需 |
| 信号层邻接参考平面 | 每个信号层有连续参考 | 阻抗受控 |
| 阻抗测试点 | 设计预留测试焊盘 | 出货验证 |

> 中文提醒：把这份清单逐项核对后，把结果做成 PASS/FAIL/NOT VERIFIED 表格交付。**任何 FAIL 修复后重跑 DRC 再交付。**
