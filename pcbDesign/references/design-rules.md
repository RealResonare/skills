# Design Rules — 叠层、阻抗、原理图、布局、布线规则

> **中文说明**：本文件是 PCB 设计的核心规则参考：叠层规划、阻抗目标、原理图要点、布局布线规则、电源完整性。具体数值以厂商制程能力与芯片数据手册为准；AI 生成规则表时必须标注默认值与"需厂商确认"。

## 1. Stackup & Layer Count — 叠层与层数

### 1.1 选层数

| 层数 | 典型叠层 | 适用 |
|---|---|---|
| 2 层 | Signal / Signal | 低速简单板（<10MHz）、低成本 |
| 4 层 | Signal / GND / PWR / Signal | 中密度 MCU、IoT、工业（默认起点） |
| 6 层 | Signal / GND / Sig / Sig / PWR / Signal | RF 隔离、额外布线层 |
| 8 层 | Sig / GND / Sig / GND / PWR / Sig / GND / Sig | DDR、PCIe、多电源域 SoC |

**何时必须多层**：高速数字（USB/PCIe/HDMI/DDR/千兆以太网）、BGA/QFN 细间距扇出、EMC 要求、多电源轨、混合信号域隔离 [$TRAE_REF](https://frobintech.com/blog/multilayer-pcb-design-best-practices-10-expert-tips-2026/)

### 1.2 叠层原则

- **对称叠层**（防翘曲）：信号/平面层绕中心镜像。
- **每个信号层邻接一个连续参考平面**（地或电源），提供阻抗参考与回流路径。
- **电源层与信号层之间用地层隔开**；两个大电流电源层不要相邻。
- 高速信号层靠近其参考平面（外层微带 / 内层带状线）。
- 默认：FR4 1.6mm、1oz 铜（外层）、内层可 0.5oz；特殊阻抗需求用厂商叠层表。

### 1.3 阻抗目标（默认）

| 信号类型 | 单端 Z0 | 差分 Zdiff | 容差 |
|---|---|---|---|
| 普通单端（SPI/UART 高速） | 50Ω | — | ±10% |
| USB 2.0/3.0、HDMI、PCIe | 45–50Ω | 90Ω | ±10% |
| 以太网 | 50Ω | 100Ω | ±10% |
| CAN（ISO 11898） | — | 120Ω（带终端） | ±10% |

**实现**：用 EDA 阻抗计算器（KiCad 内建、Saturn PCB、SI9000）按厂商叠层参数算线宽/间距；提交 Gerber 前把阻抗需求写进制造说明（不要指望板厂猜）。

## 2. Schematic Rules — 原理图要点

1. **ERC 0 error**（电气规则检查）；警告需解释。
2. 每个电源轨：标注电压/电流/去耦电容数量；电源符号用电源端口而非文本标签。
3. 每个 IC 电源脚近端配去耦电容（0.1µF 典型 + 1–10µF 大容量按需）。
4. 上拉/下拉、ESD 保护（接口）、极性标记（电解/二极管）齐全。
5. 网络命名规范：`3V3`、`VIN`、`I2C_SDA`、`UART_TX`、`nRESET`（低有效用 `n` 前缀）。
6. 原理图与 PCB 网表 100% 一致（Compare ECO 验证）。

## 3. Placement Rules — 布局规则

| 项 | 规则 |
|---|---|
| 去耦电容 | 距电源脚 ≤3mm，走线短、低电感路径（电容→引脚→过孔） |
| 晶振/时钟 | 距主芯片 ≤10mm；下方禁走线、铺地屏蔽 |
| 电源模块 | Buck 输入电容距 Vin ≤3mm；LDO 输出电容在负载同面 |
| 接口连接器 | 板边布置；USB/HDMI 等加 ESD 防护 |
| 功率器件 | 散热面朝外；与散热器/导热垫配合；大电流路径短而宽 |
| 模拟/数字 | 分区分割；ADC 等敏感模拟远离开关电源 |
| 关键器件 | CPU/FPGA 近板中心，远离板边应力区 |

## 4. Routing Rules — 布线规则

### 4.1 线宽与载流（IPC-2152 参考）

- 默认最小线宽/间距：`6/6mil`（4 层板典型）；低成本 2 层板可 `8/8mil`；高速细间距 `4/4mil`（需厂商确认）。
- 载流：1oz 铜外层层 10mil 线 ≈ 0.5A；大电流按 IPC-2152 查表或加宽/开窗加锡。
- 电源轨：先算电流再定线宽，宁宽勿窄；核心电源可用铺铜。

### 4.2 过孔

- 最小机械钻孔 ≥ 0.2mm；HDI 激光孔 ≥ 0.1mm；孔径比（板厚/孔径）≤ 8:1（标准）、10:1（先进）、12:1（HDI）。
- 过孔到过孔 ≥ 0.2mm；到走线 ≥ 0.15mm；环形圈 ≥ 0.1mm（标准）。
- 高速信号（>5Gbps）过孔残桩需背钻（back-drill），深度留 0.2mm 余量。
- 平面连接的过孔用热焊盘（4 辐条、辐条宽 0.25mm 典型），除非载流需要直连。

### 4.3 走线规则

- 弯角用 45° 或圆弧，**避免 <45° 锐角**（蚀刻酸阱）。
- 差分对：间距一致性偏差 <10%（全程）；对内等长。
- 高速总线：DDR 数据组内 ±5mil、时钟 ±2.5mil；串行总线走带状线避免参考面分割。
- 高速信号过孔限制：10Gbps ≤2 个过孔，PCIe Gen3 ≤3 个。
- 走线到板边：V-cut ≥0.25mm、铣边 ≥0.15mm。

### 4.4 电源完整性 (PDN)

- 磁珠前后电容值差 100 倍（如 10µF + 0.1µF）。
- 核心电源铺铜 + 必要时开窗加锡；去耦网络按目标阻抗法（Ztarget = Vripple/ΔI）。
- 多电源轨分层铺设；避免电源层分割穿过高速信号下方。

## 5. DRC 配置建议（KiCad）

KiCad 设计规则文件（`design_rules.kicad_dru`）可配置：间距、线宽、过孔尺寸、差分对、长度匹配。推荐起步：

- 间距：6mil（默认）
- 线宽最小/推荐：6mil / 10mil（电源 20mil+）
- 过孔：孔径 0.3mm / 焊盘 0.6mm（4 层默认）
- 丝印最小字高 0.8mm、线宽 0.15mm

> 中文提醒：KiCad MCP 服务器可运行时自动读取/写入这些规则；手写规则前先确认厂商制程能力表（最小线宽/间距/孔径/板厚）。
