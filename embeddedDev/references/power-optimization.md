# Power Optimization — 功耗优化

> **中文说明**：本文件规范低功耗设计：睡眠模式、时钟门控、唤醒源、电池数学与测量清单。目标是把"电池能用多久"从猜测变成可交付的计算。

## 1. Sleep Modes — 睡眠模式怎么选

| 模式 | 电流量级 | 特点 | 适用 |
|---|---|---|---|
| Run | 数 mA–数十 mA | 全速运行 | 正常执行 |
| Sleep / Light-sleep | 数百 µA | CPU 停，外设/时钟跑；任何中断可唤醒 | 周期性任务间隙 |
| Deep-sleep / Standby | 1–10 µA | 大部分外设关，仅 RTC/唤醒源 | 长待机 |
| Shutdown / Off | <1 µA | 仅电源域/唤醒引脚 | 极低功耗产品 |

> 中文提醒：不同芯片命名不同（ESP32 Light-sleep/Deep-sleep；STM32 Sleep/Stop/Standby；nRF 全系列丰富睡眠档），以数据手册"低功耗模式表"为准。

## 2. Design Checklist — 低功耗设计清单

1. **睡眠策略**：没事就睡（事件驱动而非轮询）。主循环 `WFI/WFE` 或 `taskENTER_CRITICAL` 后 `__WFI()`；RTOS 空闲任务默认进入睡眠。
2. **时钟门控**：不用外设立即 `DeInit`/关时钟（`__HAL_RCC_xxx_CLK_DISABLE()`）；进入睡眠前关所有不必要外设。
3. **唤醒源**：RTC 闹钟（周期唤醒）、外部中断（GPIO 唤醒）、定时器唤醒。唤醒后重新初始化被关的外设。
4. **GPIO 状态**：睡眠前把悬空输入设成输出或固定电平（悬空引脚漏电是隐藏杀手）。
5. **外设电流**：关闭未用的 ADC 参考、运放、LCD 背光；LED 用 PNP 高边驱动避免常亮漏电。
6. **电压域**：如果芯片支持，运行核心降频（如 80MHz→40MHz 功耗减半）或 DVFS。
7. **调试口**：正式低功耗验证时断开 SWD 调试器（调试器本身会灌电，导致测不准）。

## 3. Battery Math — 电池寿命计算

```
电池容量 (mAh) / 平均电流 (mA) × 0.85（老化/效率系数） ≈ 寿命 (小时)
```

**平均电流估算**（任务型负载）：

```
I_avg = (T_run × I_run + T_sleep × I_sleep + T_off × I_off) / (T_run + T_sleep + T_off)
```

示例：某设备每 60s 唤醒一次，唤醒 100ms 跑 20mA，其余睡眠 3µA：

```
I_avg = (0.1 × 20 + 59.9 × 0.003) / 60 ≈ 0.0363 mA = 36.3 µA
寿命 = 1000 mAh / 0.0363 mA × 0.85 ≈ 23,400 h ≈ 2.7 年
```

**交付时给出**：`I_run`、`I_sleep`、占空比、计算出的平均电流与寿命，并标注"实测为准"。

## 4. Measurement Checklist — 测量清单

1. 用**低电流档串口电流表/源表**（µA 级需要万用表 µA 档或专用仪表；普通 A 档分辨率不够）。
2. 断开调试器再测（见上）。
3. 测睡眠电流时确认已进入睡眠（`WFI` 执行后），不要在初始化阶段测。
4. 分模块测量：分别关掉外设看电流变化，定位耗电大户。
5. 电池供电产品注意：电池自放电、ESR 随温度变化、LDO vs DCDC 效率（DCDC 效率高但静态电流可能大）。

## 5. Common Pitfalls — 常见坑

| 坑 | 现象 | 解决 |
|---|---|---|
| 悬空 GPIO | 睡眠电流异常高 | 设固定电平或输出 |
| 忘关外设时钟 | 电流比预期高很多 | 睡眠前 DeInit 全部外设 |
| 调试器挂着测 | 电流虚高 | 拔调试器 |
| 唤醒后外设没重配 | 唤醒即死机/行为异常 | 唤醒回调里重新初始化 |
| 用轮询代替事件 | 无法睡眠 | 改中断/事件驱动 |
