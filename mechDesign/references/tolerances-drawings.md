# Tolerances & Drawings — 公差与工程图

> **中文说明**：本文件规范公差标注（GB/T 1800/1804）、形位公差（GB/T 1182）、表面粗糙度（GB/T 1031）、工程制图（GB/T 17450/4459/131）与 BOM。目标是图纸"工厂不用问就能做"。

## 1. 公差等级（GB/T 1800.2 线性尺寸）

| 应用 | 建议等级 | 典型值（举例） |
|---|---|---|
| 精密配合（轴承座、定位销） | IT5–IT7 | 30mm 孔 IT7 ≈ +0.021 |
| 一般配合（轴孔间隙/过渡） | IT7–IT9 | |
| 一般加工（板件、非关键） | IT10–IT12 | |
| 未注公差（图纸不标时） | GB/T 1804-m（中等级） | ±0.1（≤6mm）/ ±0.2（6-30mm） |

**配合制（GB/T 1800.1）**：基孔制 H（孔）+ 轴公差带；常用配合：
- 间隙：H7/g6（滑动）、H7/f7（宽间隙）
- 过渡：H7/js6、H7/k6（定位）
- 过盈：H7/p6（压入）、H7/r6（轴承外圈）

**标注示例**：`Ø30 H7/g6`（孔 H7、轴 g6）；`Ø20 H7`（孔公差带，轴未注 GB/T 1804-m）。

## 2. 未注公差（GB/T 1804）

| 精度等级 | ≤6mm | 6-30mm | 30-120mm | 120-400mm |
|---|---|---|---|---|
| f（精密） | ±0.05 | ±0.05 | ±0.1 | ±0.15 |
| m（中等级，默认推荐） | ±0.1 | ±0.2 | ±0.3 | ±0.5 |
| c（粗糙） | ±0.3 | ±0.5 | ±0.8 | ±1.2 |

图纸标题栏注明"未注公差按 GB/T 1804-m"。

## 3. 形位公差（GB/T 1182 GD&T）

| 符号 | 含义 | 典型应用 |
|---|---|---|
| ⏤ | 直线度 | 导轨、轴心线 |
| ⏥ | 平面度 | 安装面、法兰面 |
| ◯ | 圆度 | 轴承位 |
| ⌭ | 圆柱度 | 精密轴 |
| ⟂ | 垂直度 | 安装面垂直基准 |
| ∥ | 平行度 | 导轨副 |
| ◎ | 同轴度 | 轴肩、多段轴 |
| ⊕ | 位置度 | 孔组、装配基准 |

**基准体系**：A/B/C 主次基准按功能选（先功能面/装配基准，后加工基准）；**基准优先选加工时易建立的面**。

**标注示例**：`⟂ 0.05 A`（相对 A 面垂直度 0.05mm）。

## 4. 表面粗糙度（GB/T 1031 / ISO 4287）

| Ra (µm) | 加工方式 | 应用 |
|---|---|---|
| 0.4–0.8 | 磨削/精车 | 轴承配合面、密封面 |
| 1.6 | 精车/精铣 | 一般配合面、滑动面 |
| 3.2 | 半精加工 | 普通加工面 |
| 6.3–12.5 | 粗加工 | 非配合面 |
| 25+ | 铸造/锻造面 | 毛坯面（一般标注不去除材料） |

**规则**：只对功能需要的面标粗糙度（每多一个严要求=多一道工序=贵）；其余面"其余 Ra 12.5"统一标注。

## 5. 工程制图规范（GB/T 17450/4459/131）

- 图线：粗实线（可见轮廓）、细实线（尺寸/剖面）、虚线（不可见）、点画线（中心线）——线型按 GB/T 17450。
- 视图：主视图+必要的俯/侧/剖视；剖视用剖面线（45°细实线）。
- 尺寸标注：尺寸线/界线/箭头规范（GB/T 4458.4）；封闭尺寸链避免（基准明确）。
- 技术要求：热处理、表面处理、未注公差、圆角倒角（GB/T 6403.4）等文字说明。
- 标题栏：图号、名称、材料、比例、设计/校对/日期、版本。
- 比例：1:1 优先；大件 1:2/1:5，小件 2:1/5:1。

**图纸检查清单**：所有功能尺寸已标注 ✓、基准与形位公差齐全 ✓、粗糙度合理 ✓、技术要求完整 ✓、标题栏版本号 ✓。

## 6. BOM 规范

| 层级 | 内容 |
|---|---|
| 总装 BOM | 组件→子组件→零件 树状结构 |
| 每项 | 序号、图号/型号、名称、规格、数量、材料、标准号、备注 |
| 标准件 | 标准号+规格（如 GB/T 70.1 M5×16） |
| 外购件 | 型号+品牌+供应商（可选） |

**BOM 与图纸一致性**：编号一一对应；版本变更同步更新。
