# Transmissions — 传动方案与选型

> **中文说明**：本文件是传动方案选型参考：齿轮/带/链/丝杠/连杆的对比与效率、减速器选型、电机功率倒推。核心原则：**传动链效率逐级相乘**、**方案至少 2-3 套对比**、**标准件优先**。

## 1. 传动方式对比

| 传动 | 效率 | 特点 | 适用 |
|---|---|---|---|
| 齿轮（直/斜/锥） | 0.96–0.99/级 | 精确、紧凑、寿命长 | 高速比、高精度、大扭矩 |
| 同步带 | 0.95–0.98 | 无级变速、减振、免润滑 | 中等精度、跨距传动 |
| 链条 | 0.96–0.98 | 耐磨、耐温、低速大扭矩 | 输送、农机 |
| 蜗轮蜗杆 | 0.40–0.85 | 大减速比、自锁（单头） | 低速、自锁要求 |
| 滚珠丝杠 | 0.90–0.95 | 直线运动、高精度 | 数控、精密定位 |
| 行星减速器 | 0.94–0.97/级 | 高减速比、同轴、紧凑 | 伺服电机配套 |
| 连杆机构 | — | 轨迹/运动规律设计 | 机构运动（非传动效率优先） |

## 2. 传动链效率倒推（电机功率选型）

**规则**：电机 → 联轴器 → 减速器 → 同步带 → 丝杠，每级效率 0.95–0.98，多级相乘后可能只剩 80%。选电机功率必须按整链效率倒推：

```
P_motor = P_load / (η₁ × η₂ × η₃ × ...)
```

示例：负载需 1.0kW，经过 联轴器(0.99)×减速器(0.96)×同步带(0.96)：

```
P_motor = 1.0 / (0.99 × 0.96 × 0.96) ≈ 1.10 kW → 选 1.5kW（留 30%+ 裕量）
```

## 3. 减速器选型三要素

| 检查项 | 规则 | 说明 |
|---|---|---|
| 安全系数 | 峰值扭矩/额定扭矩 ≥ 1.5 | 冲击工况 |
| 惯量比 | 负载惯量/电机惯量 ≤ 5 | 动态响应与稳定性 |
| 许用径向/轴向力 | 小于减速器规格值 | 皮带轮/齿轮直装时检查 |

选型流程：算负载扭矩与转速 → 定减速比 → 查减速器额定扭矩 ≥ 负载/效率 × 安全系数 → 校核惯量比与径向力。

## 4. 齿轮初步设计（详细校核见 calculations.md / GB/T 3480）

1. 定传动比 i = z₂/z₁；小齿轮齿数 z₁ ≥ 17（直齿，防根切，标准齿形）。
2. 按接触强度粗定中心距或模数（经验：闭式软齿面按接触强度、硬齿面按弯曲强度主导）。
3. 模数取标准值（GB/T 1357：1, 1.25, 1.5, 2, 2.5, 3, 4, 5, 6, 8, 10...）。
4. 齿宽系数 ψd = b/d₁（一般 0.8–1.2）；齿宽取整。
5. 材料：软齿面 45#调质/40Cr；硬齿面 20CrMnTi 渗碳淬火。
6. **必须校核**：齿面接触强度（点蚀）与齿根弯曲强度（断齿），按 GB/T 3480（ISO 6336）方法 B，安全系数 SH/SF ≥ 1.0（一般取 1.2–1.5）。

## 5. 同步带选型要点

1. 选带型（MXL/XL/L/H... 或 5M/8M/14M）按功率与转速查选型表。
2. 带宽按功率修正（载荷系数、齿数系数）。
3. 中心距与带长：`带长 = 2C + π/2(D1+D2) + (D2-D1)²/(4C)`；张紧轮或可调中心距。
4. 最小齿数：小带轮齿数 ≥ 表值（转速越高要求越多齿）。

## 6. 滚珠丝杠选型要点

1. 轴向载荷与速度 → 选丝杠直径与导程：`V = n × P`（n 转速、P 导程）。
2. 轴向刚度与临界转速：细长丝杠校核临界转速（`n_cr` 与长度²成反比）与压杆稳定。
3. 精度等级（C3/C5/C7）按定位精度要求；预压方式按负载特性（定位/重载）。
4. 寿命：额定动载荷 Ca 按 `L10 = (Ca/Fa)³ × 10⁶` 转估算。

## 7. 电机-负载匹配经验

- 电机额定扭矩 ≥ 负载扭矩/传动效率 × 1.5（安全系数）。
- 加速扭矩：`T_acc = J_total × α`（J 为折算到电机轴的惯量，α 为角加速度）。
- 峰值扭矩（含加速）≤ 电机峰值扭矩；连续有效扭矩 ≤ 电机额定。
