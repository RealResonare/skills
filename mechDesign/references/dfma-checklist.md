# DFMA Checklist — 面向制造与装配的设计

> **中文说明**：DFMA = Design for Manufacturing and Assembly（面向制造与装配的设计）。目标：**零件数最少、对称化、防呆、不过定位、好加工、好装配**。交付设计前逐项核对。

## 1. 零件数最小化 (Part Count)

| 检查项 | 说明 |
|---|---|
| 能合并的零件合并 | 支架+法兰一体；齿轮+轴一体（小件） |
| 减少紧固件 | 用卡扣/压铆/焊接替代螺栓组（但考虑可维护性） |
| 模块化 | 组件独立可测试；共用件/标准件优先 |
| 对称件共用 | 左右对称件用一个零件（减少开模/刀具） |

**评估**：`装配效率 = 理论最少零件数 / 实际零件数`——接近 1 说明设计好。

## 2. 对称化与防呆 (Symmetry & Poka-Yoke)

| 检查项 | 说明 |
|---|---|
| 零件对称 | 对称零件无需区分方向，装配快且不易错 |
| 不对称件加防呆 | 定位销不对称、键槽偏心、倒角差异 |
| 安装方向唯一 | 设计成"只有一种装法"（或错误装法会立即发现） |
| 连接器防呆 | 防反插、防错位（DC 座、排针方向） |

## 3. 过定位检查 (Over-constraint)

- **"定位宁少勿多"**：平面用 3 点、圆周用 2 点 + 防转、轴向 1 面。
- 过定位（两个面同时限制同一自由度）→ 装配应力、加工公差敏感。
- 案例：两个定位销 + 端面同时限制 → 公差冲突装不上。

## 4. 可制造性 (Manufacturability)

| 工艺 | 检查项 |
|---|---|
| 机加工 | 避免内尖角（给退刀槽/圆角）；深孔注意长径比；薄壁件刚性 |
| 铸造 | 壁厚均匀、拔模斜度、圆角 ≥0.2×壁厚、避免热节（见 materials.md） |
| 钣金 | 折弯半径 ≥ 板厚、最小孔边距 ≥2×孔径 |
| 焊接 | 双面坡口、焊后去应力（见 materials.md） |
| 注塑 | 拔模斜度 1-3°、壁厚均匀（1-3mm 典型）、避免厚薄骤变 |

## 5. 可装配性 (Assemblability)

| 检查项 | 说明 |
|---|---|
| 装配顺序 | 定义清晰的装配顺序；后装的零件不妨碍前装 |
| 工装可达性 | 扳手/螺丝刀空间；O 形圈/轴承压装路径 |
| 公差链 | 关键配合的尺寸链计算（轴向累计误差） |
| 标准件易得 | 用市售标准件（轴承/螺钉/挡圈），不自定义 |
| 润滑/维护 | 需润滑点可达；滤芯/电池可更换 |

## 6. 标准件优先 (Standard Parts)

| 类别 | 常用标准 |
|---|---|
| 螺栓/螺钉 | GB/T 5782、GB/T 70.1（内六角）、GB/T 818 |
| 垫圈/挡圈 | GB/T 97、GB/T 894 |
| 轴承 | GB/T 276（深沟球）、GB/T 283（圆柱滚子） |
| 键 | GB/T 1096（平键） |
| 弹簧 | GB/T 2089（圆柱螺旋压缩） |
| O 形圈 | GB/T 3452.1 |

**规则**：能用标准件就用标准件——成本低、货期短、可更换；非标件需给出理由。

## 7. 评审交付物

- [ ] 零件数/装配效率统计
- [ ] 防呆设计清单（方向唯一性验证）
- [ ] 过定位检查结论
- [ ] 每零件可制造性检查（工艺×特征）
- [ ] 装配顺序说明
- [ ] 标准件清单（含标准号）

> 中文提醒：DFMA 评审结果做成 PASS/WARN/FAIL 表格交付；WARN 项给出改进建议，FAIL 项必须修改后重评。
