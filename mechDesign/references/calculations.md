# Calculations — 强度/刚度/疲劳/振动校核

> **中文说明**：本文件是机械设计的"计算校核四件套"：强度、刚度、疲劳、振动。**每一项都必须给出公式、代入数值与结果**。数值为通用参考，材料数据以标准/质保书为准。

## 0. 安全系数（起步）

| 工况 | 安全系数 n |
|---|---|
| 轻载（静载、均匀） | 1.5 |
| 一般（通用机械） | 2.0 |
| 重载/冲击/不确定 | 3.0+ |

**旋转轴**：ASME B106.1M / Shigley 方法，安全系数按冲击载荷分级（Kt 扭转冲击 1.0/1.5/2.0，Kb 弯曲冲击 1.5/2.0/3.0）[$TRAE_REF](https://www.steelsolver.com/p/shaft-design-calculator.html?m=1)

## 1. 静强度

- 拉伸/压缩：`σ = F/A ≤ [σ] = σs/n`
- 弯曲（圆截面）：`σ = 32M/(πd³)`（M 为弯矩）
- 扭转（圆截面）：`τ = 16T/(πd³)`（T 为扭矩）
- 组合载荷（轴）：Von Mises 等效应力 `σeq = √(σb² + 3τ²)`；Tresca `τmax = ½√(σb² + 4τ²)`
- 所需直径（Von Mises，实心圆轴）：`d = [16/(πσallow) · √(4M² + 3T²)]^(1/3)`

**薄壁压力容器**：`σ = p·D/(2t)`（环向）——校核壁厚。

## 2. 刚度（挠度/扭转角）

**规则：刚度往往比强度先到极限**——精密轴、丝杠、悬臂梁先按刚度反推截面。

- 简支梁中点集中力：`δ = FL³/(48EI)`
- 悬臂梁端部集中力：`δ = FL³/(3EI)`
- 圆截面惯性矩 `I = πd⁴/64`；抗扭截面模量 `Wp = πd³/16`
- 扭转角：`θ = TL/(G·J)`，`J = πd⁴/32`（极惯性矩）
- 常用许用挠度：传动轴跨中 ≤ (0.0003–0.0005)L；机床主轴按精度等级更严
- 悬臂/长轴：按静挠度限值反推直径

## 3. 疲劳校核（交变载荷必须做）

**规则：静强度只是底线**。受交变载荷的零件必须做疲劳校核。

### 3.1 修正疲劳极限

```
σe = k_a × k_b × k_c × k_d × σe'
```

- σe'：材料疲劳极限（钢 σe' ≈ 0.5σb，弯曲）
- k_a 表面系数（抛光 1.0 / 磨削 0.9 / 机加工 0.8 / 热轧 0.66 / 锻造 0.57）
- k_b 尺寸系数（大尺寸减小）
- k_c 可靠性系数（50%=1.0，90%=0.897，95%=0.868，99%=0.814）
- k_d 温度系数

### 3.2 平均应力修正

| 准则 | 公式（σm 平均应力, σa 幅值） | 保守度 |
|---|---|---|
| Goodman | σa/σe + σm/σb = 1/n | 中等 |
| Soderberg | σa/σe + σm/σs = 1/n | 最保守 |
| Gerber | σa/σe + (σm/σb)² = 1/n | 最不保守 |

### 3.3 应力集中

- **Kt 必须查图或仿真，不能拍脑袋**（键槽 1.3–1.6、轴肩圆角 1.5–2.5、横孔 2.4、卡环槽 2.0、压配合 2.0）。
- 疲劳缺口敏感度 q 修正：`Kf = 1 + q(Kt − 1)`。

### 3.4 不规则载荷

- **雨流计数 + Miner 线性累积损伤**：`Σ(ni/Ni) ≤ 1`（ni 为第 i 级应力循环次数，Ni 为该应力下寿命）。
- 输出寿命：N₁₀⁶（有限寿命）或 N∞（无限寿命）。

## 4. 振动校核（重中之重）

**规则：旋转机械必须算一阶固有频率，避开工作转速 ±20%**；不做模态校核的旋转设计是埋雷。

- 轴一阶临界转速（集中质量近似）：`ω_cr = √(k/m)`（k 刚度、m 等效质量）；或按连续轴公式。
- 工作转速 n_work 需满足：`n_work < 0.8 × n_cr` 或 `n_work > 1.2 × n_cr`（避开共振区）。
- 梁一阶固有频率（悬臂）：`f₁ = (1.875²/2πL²)·√(EI/(ρA))`。
- 薄壁件/大跨度结构：做模态思维检查（激励源频率 vs 结构固有频率）。
- 电机/泵基础：隔振或动力反力校核。

## 5. 标准件校核速查

### 5.1 螺栓连接

- 预紧力 `F0 ≈ 0.6–0.7 × σs × As`（As 应力截面积）。
- 防松：交变载荷/振动工况必须防松（弹簧垫圈/锁紧螺母/螺纹胶/法兰面）。
- 校核：`σ = F0/As ≤ [σ]`；受横向载荷的普通螺栓按预紧产生的摩擦力校核。

### 5.2 轴承寿命（ISO 281）

- 额定寿命：`L10 = (C/P)^p × 10⁶` 转（球轴承 p=3，滚子轴承 p=10/3）。
- 小时寿命：`L10h = (10⁶/(60n)) × (C/P)^p`。
- P 为当量动载荷：`P = X·Fr + Y·Fa`（径向/轴向系数查样本）。

### 5.3 键连接

- 平键挤压应力：`σp = 2T/(d·l·(h/2)) ≤ [σp]`（T 扭矩、d 轴径、l 键长、h 键高）。
- 剪切应力：`τ = 2T/(d·l·b) ≤ [τ]`（b 键宽）。

### 5.4 齿轮（GB/T 3480 / ISO 6336）

- 齿面接触强度（点蚀）安全系数 SH ≥ 1.0–1.2（方法 B）。
- 齿根弯曲强度（断齿）安全系数 SF ≥ 1.0–1.2。
- 输入扭矩：`T₁ = 9550 × P(kW) / n₁(rpm)` N·m。

## 6. 计算报告模板

【已知条件】P=7.5kW, n=1450rpm, 轴径 d=40mm, 材料 45#调质 σs=355MPa
【1 扭矩】T = 9550×7.5/1450 = 49.4 N·m

【3 安全系数】n = τs/τ = (0.5×355)/3.93 = 45 >> 2.0 ✅
