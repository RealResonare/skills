# Materials — 材料与热处理

> **中文说明**：本文件是机械设计选材参考：钢/铝/不锈钢牌号矩阵、热处理标注、铸锻焊注意事项、典型力学性能。数值为通用参考，最终以材料标准（GB/T 699、GB/T 3077 等）与供应商质保书为准。

**选材逻辑**：先定功能（强度/刚度/耐蚀/耐磨/轻量/成本）→ 查矩阵选候选 → 校核强度刚度（见 calculations.md）→ 考虑热处理与加工性 → 定牌号。

## 2. 热处理标注（图纸上）

| 处理 | 目的 | 图纸标注示例 |
|---|---|---|
| 退火 | 降低硬度、消除内应力 | 退火 HB170-200 |
| 正火 | 细化晶粒、改善加工性 | 正火 HB≤220 |
| 调质 | 综合力学性能（σs↑、韧性） | 调质 HB240-280 |
| 淬火+回火 | 高硬度 | 淬火回火 HRC40-45 |
| 表面淬火 | 表面耐磨、心部韧 | 表面淬火 HRC50-55，深 1-1.5mm |
| 渗碳淬火 | 齿轮/花键表面硬化 | 渗碳淬火 HRC58-62，深 0.8-1.2mm |
| 氮化 | 高耐磨、变形小 | 氮化 HV800 以上 |

> 中文提醒：热处理标注必须写清楚——**处理方式 + 硬度范围 + 硬化层深度**；调质件写硬度范围即可（HRC 或 HB 择一）。

## 3. 结构件工艺注意事项

### 3.1 焊接件

- 焊缝优先双面坡口（背面成形可控）；焊后去应力退火或振动时效，否则精加工后变形。
- 焊接箱体设人孔/工艺孔，便于内部清理与探伤。
- 厚板对接开坡口；角焊缝按受力计算焊脚高度 ≥ 1.2×薄板厚（经验起步）。

### 3.2 铸件

- 壁厚均匀（推荐 5–25mm），最薄处不小于工艺最小壁厚（铸铁 4-6mm、铸铝 3-5mm）。
- 铸造圆角 R ≥ 0.2×相邻壁厚，避免热节与裂纹。
- 铸件许用应力取静强度的 0.6–0.8（铸造缺陷）。

### 3.3 钣金件

- 折弯半径 R ≥ 板厚 t（不锈钢 ≥ 1.5t，软铝 ≥ 0.8t）。
- 最小孔边距 ≥ 2×孔径（防翻边撕裂）；冲裁最小孔径 ≥ 板厚（软料）。
- 尺寸链计算考虑折弯展开系数（K 因子 0.3–0.5）。

## 4. 滑动摩擦 PV 值（摩擦副寿命）

| 材料副 | 允许 PV (MPa·m/s) | 说明 |
|---|---|---|
| 铜合金（锡青铜等） | ≤ 1.5 | 滑动轴承传统选择 |
| 自润滑工程塑料（POM/PTFE 填充） | ≤ 0.3 | 免润滑 |
| 粉末冶金含油轴承 | 0.1–0.3 | 轻载 |

**PV 检查**：`P = 载荷/投影面积`，`V = 圆周速度`；P·V 超限 → 发热磨损快。
